# Phase 2 — Reproducibility, scientific interpretation, and release notes

**Status:** Portfolio documentation complete based on reported GitHub Actions PASS results (November 2026).  
**Scope:** Educational mouse ChIP-seq alignment/QC and bacterial haploid variant analysis.  
**Not for clinical diagnosis or clinical decision-making.**

## Evidence hierarchy and results

1. **Python checks — PASS (reported):** Dependency installation, syntax checks, published-result regression tests, and QC report regression tests.
2. **Synthetic end-to-end — PASS (reported):** Synthetic paired-end reads processed by the existing BWA → SAMtools → BCFtools pipeline; known synthetic mutations were recovered. This checks the software workflow on a controlled fixture.
3. **Original bacterial dataset — PASS (reported):** Original input files downloaded and verified by MD5; variant calling rerun on an independent GitHub Actions runner; output compared to the committed baseline using normalized `CHROM, POS, REF, ALT` (case-insensitive alleles).

| Original dataset comparison | Baseline | Newly called |
|---|---:|---:|
| Total variant records | 19 | 19 |
| SNP records | 12 | 12 |
| Indel/complex records | 7 | 7 |
| Missing variant records | — | 0 |

**Interpretation:** All 19 normalized variant identities matched the committed baseline. This establishes computational reproduction for this dataset and these settings. It does **not** establish independent biological correctness, complete VCF equality, or validated clinical performance. Evidence of the exact run, including tool versions and input checksum output, should be retained as the downloadable GitHub Actions artifact.

## Inputs, provenance, and reproducibility

- **Bacterial training dataset:** [Zenodo record 582600](https://zenodo.org/records/582600); paired-end `mutant_R1.fastq`, `mutant_R2.fastq`, and `wildtype.fna` reference.
- **Reference:** Single 197,394-bp fragment, FASTA record `Wildtype`; not a whole bacterial genome.
- **Mouse ChIP-seq training dataset:** [Zenodo record 1324070](https://zenodo.org/records/1324070); mouse mm10 alignment/QC is a **separate** workflow and was **not** independently rerun in Phase 1B.
- Raw FASTQ and reference files are intentionally excluded from Git. Check dataset licensing and redistribution conditions at source before sharing them.
- The manual workflow `.github/workflows/ngs-original-dataset-reproduction.yml` performs source-file MD5 verification and saves tool versions and comparison results as run artifacts (retention configured in the workflow). Refer to a specific successful run and artifact for audit evidence; this document is a summary, not a substitute for its logs.

### How to reproduce from GitHub.com

1. Open the repository **Actions** tab.
2. Select **NGS original dataset reproduction**.
3. Select **Run workflow**, branch `main`, and start the run.
4. Check the download/checksum, alignment, VCF normalization, and baseline comparison steps.
5. Download the `original-dataset-reproduction-evidence` artifact and inspect `reproduction_summary.md`, `reproduction_comparison.tsv`, `input_checksum_results.txt`, and `tool_versions.txt`.

This workflow is intentionally **manual-only**; existing automatic CI workflows should remain unchanged.

## Coverage and QC interpretation

Coverage values are from the committed bacterial reference-fragment analysis (`results/variant_pipeline/coverage_summary.tsv`):

| Metric | Value |
|---|---:|
| Reference length | 197,394 bp |
| Mean depth | 18.9468× |
| Bases covered at ≥1× | 180,650 (91.5175%) |
| Bases covered at ≥10× | 179,213 (90.7895%) |
| Bases covered at ≥20× | 98,372 (49.8354%) |
| Bases with no coverage | 16,744 |
| Bases below 10× | 18,181 |
| Contiguous low-coverage regions (threshold <10×) | 67 |

A mean depth of ~19× does not imply that all positions are adequately covered: ~9.21% of the reference is below 10× and ~50.16% is below 20×. Interpretation should account for low-coverage regions, alignment quality, local sequence complexity and read-level support. These are descriptive QC metrics, not validated acceptance thresholds.

The committed analysis reports 19 candidate variant records (12 SNPs and 7 indels). High QUAL, read depth, and a high alternate-allele fraction do not independently prove that each variant is biologically true.

## Known limitations and unresolved questions

- **No independent biological truth set:** The reproduced calls were compared with a baseline generated by the same analysis approach. Concordance is not sensitivity/specificity or ground-truth accuracy.
- **Nearby deletions:** Read-level co-occurrence evidence and VCF allele-depth (`FORMAT/AD`) counts are not yet fully reconciled. Possible contributors require further examination of read filtering, CIGAR representation, strand, and normalization; no cause is asserted here.
- **Fragment reference:** The 197,394-bp bacterial reference is not a complete genome. Mapping and coverage findings apply to the supplied fragment.
- **Educational data:** Filtering criteria and report PASS/WARN checks are illustrative, not clinically validated.
- **Scope of automated reproduction:** Phase 1B covers bacterial variant calling, not a fresh end-to-end reproduction of the mouse ChIP-seq workflow.
- **Workflow environment:** Versions used in original local analysis can differ from packages installed by Ubuntu Actions; inspect each run's saved `tool_versions.txt` rather than assuming exact versions.
- **Publication permissions:** Confirm collaborator authorization to publish contributed code, figures, and derived outputs and confirm third-party licensing before declaring a public release.
